# NochOtel

Веб-приложение для учёта номерного фонда вахтовых гостиниц (прообраз — «БИТ:Отель 8» для АО «Хиагда»).
Два портала на единой базе: **рабочий стол персонала** (учёт, размещение, отчёты) и **личный кабинет вахтовика** (где живу, что в номере, соседи, о доме и посёлке).

## Архитектура

- **Frontend:** Vue 3 + Vite + Vue Router + Pinia (`web/`). Сборка отдаётся бэкендом.
- **Backend:** Node.js + Express + SQLite (`better-sqlite3`), JWT-авторизация (`server/`).
- **Один сервер:** Express раздаёт собранный фронтенд (`dist/`) и API (`/api`).
- Тема и токены оформления — Noctrinth/Modrinth (тёмная / светлая).

## Роли и порталы

| Роль | Портал | Права |
| --- | --- | --- |
| **Администратор** | `/app` | Полный доступ + пользователи + журнал действий |
| **Редактор** | `/app` | Гостиницы, номера, брони, проживающие |
| **Просмотр** | `/app` | Только просмотр шахматки и отчётов |
| **Вахтовик** | `/me` | Своё размещение, соседи, удобства, о доме (только своё) |

Аккаунты вахтовиков создаёт администратор в разделе **Пользователи** (роль «Вахтовик» + привязка к карточке проживающего). Войдя, вахтовик видит только свой кабинет; служебные эндпоинты для него закрыты.

Анонимный поиск номера без входа — страница **«Найти свой номер»** (`/find`).

## Возможности

**Персонал:** дашборд (загрузка, заезды/выезды, стадии брони, тренд 14 дней) · гостиницы → номера → места · цветовые статусы · стадии брони (ожидается → проживает → выехал) · фильтры · отчёты в Excel · импорт проживающих · план этажа и шахматка · журнал действий.

**Вахтовик:** карточка размещения (дом, номер, место, период, статус) · удобства номера (Wi-Fi, душ, ТВ…) · соседи по комнате с профилями · о доме и посёлке (адрес, комендант, правила, что рядом) · свой профиль и смена пароля.

## Запуск

Нужен [Node.js](https://nodejs.org/) LTS (18+).

```bash
npm install        # зависимости (бэкенд + фронтенд)
npm run seed       # БД, статусы, классы, удобства, демо-гостиница и демо-вахтовик
npm run build      # собрать фронтенд в dist/
npm start          # сервер → http://localhost:3000
```

При первом входе откроется форма **«Создать администратора»**. Демо-вахтовик из сидов: логин `vahta`, пароль `vahta`.

### Разработка (с горячей перезагрузкой)

```bash
npm run dev        # Express (:3000) + Vite (:5173) одновременно
```

Открывать `http://localhost:5173` — Vite проксирует `/api` на бэкенд.

### Тесты

```bash
npm test           # интеграционные тесты (брони, права ролей) на временной БД
```

## Продакшен / размещение на сервере

1. Задайте окружение (см. `.env.example`): скопируйте в `.env`, пропишите **свой** `JWT_SECRET`.
   Без него секрет сгенерируется автоматически и сохранится в `data/.jwtsecret`.
2. Соберите фронтенд и запустите один процесс Node — он раздаёт и API, и `dist/`:

   ```bash
   npm ci --omit=dev && npm run build
   JWT_SECRET=... PORT=3000 npm start
   ```

3. Держите процесс живым менеджером (например `pm2 start server/index.js --name nochotel`
   или unit systemd) и поставьте перед ним reverse-proxy (nginx) с HTTPS.
4. **Бэкап:** вся база — это файл `data/nochotel.db` (+ `-wal`/`-shm`). Копируйте его по расписанию.
   Путь можно вынести на отдельный диск через `NOCHOTEL_DB`.

## Структура

```
server/      Express API + SQLite (index.js, db.js, auth.js, seed.js)
web/         Vue 3 + Vite фронтенд
  src/
    pages/     Login, Find, staff/*, resident/*
    layouts/   StaffLayout, ResidentLayout
    stores/    auth (Pinia)
    api/       клиент к /api
    styles/    токены Noctrinth + база
dist/        собранный фронтенд (генерируется)
public/      классический интерфейс (доступен на /legacy на время переноса)
data/        файл базы (создаётся при первом запуске)
```

## Схема БД

`users(resident_id) · residents(about, photo) · hotels(settlement, address, phone, rules) · rooms · beds · placements(stage) · statuses · room_classes · amenities · room_amenities · hotel_amenities · places · audit_log`

Чтобы начать с чистого листа — остановите сервер, удалите папку `data/`, затем `npm run seed`.
