# NochOtel

Веб-приложение для учёта номерного фонда вахтовых гостиниц (прообраз — «БИТ:Отель 8» для АО «Хиагда»).
Лёгкий тонкий клиент: ленточный график («шахматка») номеров по датам с цветовой индикацией статусов.

## Возможности

- **Роли:** администратор / редактор / просмотр (вахтовики доступа не имеют).
- **Первый запуск:** первый зарегистрированный пользователь автоматически получает права администратора.
- **Гостиницы → номера → спальные места → проживающие** (иерархия, классы номеров, кол-во мест).
- **Цветовые статусы** (Свободно / Забронировано / Проживает / Ремонт) с возможностью добавлять свои.
- **Шахматка** по выбранному периоду, фильтры по гостинице и классу номера, KPI-сводка.
- **Защита от двойного бронирования** — нельзя посадить двух человек на одно место в пересекающиеся даты.
- **Экраны:** Заезды/выезды на дату · Журнал размещений · Сводка по гостиницам · Журнал действий (аудит).
- **Отчёты** по номеру и по проживающему — выгрузка в Excel (`.xlsx`).
- **Импорт проживающих** из Excel (столбцы определяются по заголовкам).
- **Темы интерфейса** в стиле Noctrinth/Modrinth: тёмная / светлая.

## Технологии

- **Backend:** Node.js + Express, SQLite (`better-sqlite3`), JWT-авторизация.
- **Excel:** `exceljs` (импорт/экспорт).
- **Frontend:** ванильный SPA без сборки; кастомные элементы управления и тема в стиле Noctrinth.

Минимум трафика и зависимостей — подходит для канала Чита ↔ Бурятия.

## Запуск

Нужен установленный [Node.js](https://nodejs.org/) (LTS, версия 18+).

```bash
npm install      # установить зависимости
npm run seed     # создать БД, статусы, классы номеров и демо-гостиницу (без пользователей)
npm start        # запустить сервер → http://localhost:3000
```

При первом входе откроется форма **«Создать администратора»** — введите логин, пароль и ФИО.
Эта учётная запись получит полные права. Дальнейшие пользователи создаются админом в разделе «Пользователи».

Порт можно изменить переменной окружения `PORT` (например, `PORT=8080 npm start`).
Чтобы начать с чистого листа — остановите сервер и удалите папку `data/`, затем снова `npm run seed`.

## Развёртывание на сервере

1. Установить Node.js LTS, скопировать папку, `npm install --omit=dev`, `npm run seed`.
2. Запускать через системный сервис или `pm2` (переменные `PORT`, `JWT_SECRET`).
3. База данных — файл `data/nochotel.db` (включить в резервное копирование).

## Структура

```
server/
  index.js   Express API + бизнес-логика
  db.js      схема SQLite (создаётся автоматически)
  auth.js    JWT + проверка ролей
  seed.js    наполнение демо-данными
public/
  index.html
  css/style.css
  js/app.js, components.js, icons.js
data/        файл базы (создаётся при первом запуске)
```

## Схема БД

`users · hotels · room_classes · statuses · rooms · beds · residents · placements · audit_log`

Размещение (`placements`) = место + проживающий + статус + период — основа шахматки и отчётов.

## Роли

| Роль | Права |
| --- | --- |
| **Просмотр** | только просмотр шахматки и отчётов |
| **Редактирование** | управление номерами, бронями и проживающими |
| **Администратор** | полный доступ + управление пользователями и журнал действий |
